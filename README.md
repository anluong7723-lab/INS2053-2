## Folder guide

- `homework/week-XX/code/`: source code for the weekly homework.
- `homework/week-XX/video/`: link or notes for the OBS explanation video. Do not commit large video files.
- `exercises/`: in-class and personal practice.
- `project/`: final or semester project.
- `resources/`: saved links, downloaded slides, ebook notes and session notes.
- `docs/`: progress tracking, requirements and personal study notes.
- `submissions/`: final packaged submissions only.

## Weekly workflow

1. Read the matching ebook chapter and session.
2. Complete practice work in `exercises/`.
3. Implement the homework in `homework/week-XX/code/`.
4. Add the video URL and a short explanation to `homework/week-XX/video/README.md`.
5. Run the course self-check and record the result in the weekly `README.md`.
6. Update `docs/progress.md`.
